## 🌟 نظرة عامة على المشروع
تم تصميم المنصة لتجاوز التخمينات العشوائية في سباقات الخيول وتحويل عملية الاختيار إلى **علم حسابي متكامل**. تجمع المنصة بين:
- **تحليل المسار الحركي الديناميكي (Dynamic Pathfinding)**
- **الخوارزميات الجينية (Genetic Optimization)**
- **نماذج التعلم الجماعي (Ensemble Models)**
- **محاكاة مونت كارلو (Monte Carlo Simulation)**

كل هذه التقنيات تعمل في تناغم مباشر ولحظي مع بيانات المشاركين، الكوطات المباشرة، وحالات الحوافر وسجلات الخيالة والمدربين.

---

## 📡 المصادر والبيانات الحقيقية (Zero-Mock Data)
- **برنامج السباقات اليومي واللحظي**: يتم جلبه عبر واجهات برمجية مسندة (`/api/pmu/programme`) لعرض جميع الاجتماعات والسباقات (R1, R2, C1, C2...) ليوم السباق.
- **بيانات المشاركين التفصيلية**: تشمل الأسماء، الأرقام، الأوزان، الأحصنة، الجوكي، المدرب، العمر، الأرباح السابقة، وتفاصيل الحوافر الدقيقة (`D4` منزوع 4، `DP` منزوع خلفي، `DA` منزوع أمامي).
- **كوطات الرهان المباشرة (PMU Live Odds)**: تحديث مستمر لنسب المراهنة وحساب القيمة المتوقعة الحقيقية (EV+).
- **النتائج وتقارير الوصول الرسمية (Arrivées & Rapports)**: التحقق الفوري من الترتيب الرسمي، حساب الأرباح الحقيقية ومطابقة التوقعات مع النتائج الرسمية.

## 🧠 النماذج والخوارزميات التحليلية

### 1. تحليل المسار الحركي الديناميكي (Dynamic Pathfinding Analysis)
- حساب كفاءة أداء الحصان في المنعطفات الصعبة (`Cornering Index`) والسرعة الخطية في الخط المستقيم الأخير (`Straight Velocity`).
- تقدير مقاومة الاحتكاك الهوائي واستراتيجية التمركز (هل ينطلق في المقدمة أم يعتمد على الانقضاض المتأخر في الأمتار الأخيرة).
- **الهدف**: تعزيز دقة الترتيب الدقيق **Tiercé Ordre**.

### 2. نموذج المجموعة المخصص لتقليص الفجوة (Ensemble Quinté+ Désordre Model)
- دمج خوارزميات متعددة (Random Forest + Logistic Gradient + Elo Ratings).
- خفض فجوة التوقعات بين الخيول المفضلة ذات الكوطة المنخفضة والخيول المفاجئة (Outsiders).
- **الهدف**: رفع نسبة إصابة **Quinté+ Désordre** عبر تضمين التوازن التكتيكي الأمثل في التذاكر الخماسية.

### 3. محرك التوليفات الاحتمالية للبونص (Combinatorial Probability Engine)
- حساب الاحتمالية الرياضية التراكمية لتحقيق **Bonus 3** و **Bonus 4** و **Bonus 5** في كل تذكرة مقترحة.
- تلوين ديناميكي للتذاكر (الدرع الزمردي فائق الأمان، التوليفة الذهبية المتوازنة، وتوليفة التوكار البنفسجية لاقتناص الكوطات المرتفعة).
- **حماية رأس المال (Safeguard Coverage)**: ضمان عودة رأس المال بأرباح مضاعفة حتى عند خروج حصان واحد أو اثنين من الترتيب الرئيسي.

### 4. نظام الركيزة الذهبية والتوكار المنقذ (Golden Base & Tocard Sauveur)
- **الركيزة الذهبية (Base Solide)**: اختيار الحصان الأكثر ثباتاً وجاهزية ليكون عمود جميع التذاكر.
- **التوكار المنقذ (Tocard Sauveur)**: خوارزمية ذكية لاقتناص الحصان ذو الكوطة المرتفعة (أعلى من 15.0) الذي يملك مؤشرات فيزيكوكيميائية وحوافر D4 ترشحه لتحقيق مفاجأة مدوية ومضاعفة أرباح التذكرة.

## 🎯 استراتيجيات الرهان والبونص المستهدفة

| نوع الرهان / الجائزة | الآلية الخوارزمية المستهدفة | نسبة الحماية والتأمين |
| :--- | :--- | :--- |
| **Tiercé Ordre** | تحليل المسار الحركي + الحوافر + الجوكي | استهداف الترتيب الدقيق (1-2-3) |
| **Quinté+ Désordre** | نموذج Ensemble المتوازن بين المفضل والمفاجئ | التقاط الخمسة خيول الفائزة بأي ترتيب |
| **Quinté+ Bonus 4** | التوليفة فائقة الأمان (Emerald Shield) | احتمال نجاح يتجاوز 75% |
| **Quinté+ Bonus 3** | تغطية الركائز الثلاث الأولى بتوزيع مونت كارلو | استرداد وتأمين رأس المال بنسبة تفوق 90% |
| **Quinté+ Bonus 5** | تحليل تعثر الحصان الخامس وإحلال الخيول البديلة | تحويل تعثر الخماسي إلى أرباح مباشرة |
| **Quarté+ Bonus 3** | التركيز على الرباعي الذهبي واستغلال هوامش الخطأ | تغطية عالية للمراكز 1-2-3 في الرباعيات |

## 💎 المميزات والفوائد الرئيسية
1. **واجهة استخدام باللغة العربية بالكامل**: مصممة وفق أحدث معايير التصميم العالمي مع خط تجوال العربي فائق الوضوح.
2. **توليد تذاكر جاهزة للنسخ المباشر**: بنقرة زر واحدة يتم نسخ أرقام التذاكر التكتيكية الموصى بها.
3. **مخططات بيانية تفاعلية (Radar & Distribution Charts)**: لمقارنة الخيول من حيث مؤشر الحوافر، سجل الجوكي، اللياقة، والقيمة المتوقعة.
4. **مساعد الذكاء الاصطناعي الفوري**: وكيل تحليلي مدمج يجيب على الاستفسارات الفنية ويشرح أسباب ترشيح كل حصان.
5. **لوحة نتائج تاريخية وأرشيف التحقق**: تتبع نتائج السباقات السابقة ومقارنة توقعات الخوارزمية مع نتائج PMU الرسمية بالدرهم واليورو.

## 🚀 طريقة العمل وكيفية التشغيل والتنفيذ

### 1. المتطلبات الأساسية
- **Node.js**: الإصدار 18 أو أحدث (يوصى بـ Node.js 20+).
- **مدير الحزم**: `npm` أو `pnpm` أو `yarn`.

### 2. التثبيت والتشغيل المحلي

```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev

# 3. فتح المتصفح على العنوان
http://localhost:3000
```

### 3. بناء المشروع للإنتاج (Production Build)

```bash
# بناء النسخة الإنتاجية
npm run build

# تشغيل النسخة الإنتاجية
npm start
```

## 🛠️ البنية التقنية (Tech Stack)
- **Framework**: Next.js 15+ (App Router Architecture)
- **Language**: TypeScript (Type-Safe Strict Mode)
- **Styling**: Tailwind CSS v4 & Lucide Icons
- **Animations**: Motion (Framer Motion)
- **Data Visualizations**: Recharts & D3 Data Models
